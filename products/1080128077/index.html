Vertiv Geist Universal Rack PDU with Next-Generation IMD| 16A-48A| 11kW| 208V-415V| (30) Combination C13/C19 outlets | VP4UU0A1

Part Number: VP4UU0A1
Manufacturer: VertivType: PDUUNSPSC: 39121017
The Vertiv Geist VP4UU0A1 is a vertical rack power distribution unit with a universal input that supports common AC power configurations. It has (30) Combination C13/C19 outlets providing 11kW of power capacity. This unit can accommodate input power ranging from 16A-48A and 208V-415V in both single-phase and three-phase configurations. It helps simplify the rPDU procurement process since users can use a single model to work with different power sources. It is integrated with the Vertiv Geist Next Generation Interchangeable Monitoring Device (IMD). It has a 128x128 high-contrast LCD that displays the power usage. It features enhanced security with a secure boot that helps protect data and operations. It also has a redundant power-sharing port that connects two IMDs in the rack and provides backup power in case of power loss. The units are Dual Listed (UL/CE), TAA-Compliant, and individually tested for functionality and reliability.
